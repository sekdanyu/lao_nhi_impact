### Lao National Health Insurance

This repository contains R and Stata code for reproducing NHI study results.

* The impact of national health insurance on health services utilization in Lao People's Democratic Republic (Lao PDR): a quasi-experimental evaluation using longitudinal administrative data 
    * `/code`: code  
    * `/output`: model results  
    * `/graph`: figures
